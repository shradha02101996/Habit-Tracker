# Bloom Habit Tracker 🌷

A lightweight, private habit tracker designed to work as a website and iPhone Home Screen app.

## Features
- Cute light pink UI
- Customizable habits
- Daily completion tracking
- **+10 points when every habit for the day is completed**
- Previous-date editing
- Monthly overview with completion %, perfect days, points and best streak
- Calendar history
- Data stored locally in the browser
- PWA files included for iPhone Home Screen use

## GitHub Pages → iPhone
1. Create a GitHub repository.
2. Upload `index.html`, `manifest.json`, and `sw.js`.
3. Enable **Settings → Pages → Deploy from branch**.
4. Open the published GitHub Pages URL in Safari on iPhone.
5. Tap **Share → Add to Home Screen**.

Your habit data stays in the browser on your device via localStorage. If Safari data is cleared, the local data can be lost.
